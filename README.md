# 🛠️ IT Admin Toolkit

A Windows system administration tool for IT professionals.

## Features

- 📦 **App Deployment** — Install apps via Winget and Chocolatey (bulk install supported)
- ⚡ **PowerShell Scripts** — Run preset and custom scripts with one click
- 🌐 **Network Diagnostics** — Ping, traceroute, port scan, DNS tools, WiFi info
- 📊 **Log Analysis** — ESXi logs, Windows Event Logs, generic log files
- 🗑️ **Uninstall & Cleanup** — Scan, remove, and clean up applications
- 🔄 **Windows Updates** — Scan and install updates via PSWindowsUpdate
- 🛡️ **Defender Tools** — Diagnose and repair Windows Security

### Requirements

- Windows 10/11
- Run as **Administrator** for full functionality

### Quick Start

1. Download the `.exe` from [Releases](https://github.com/pshubert1/IT-Admin-Toolkit/releases)
2. Right-click → **Run as administrator**
3. Select a tab and start working
